# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in web UI served by the box at `/app`: chat with model/effort, projects with chat history, goals, file tree, settings, update notice.

**Architecture:** New `src/web/` modules own sessions, routes and data. One dispatch hook in `src/http-server.ts` hands `/app*` and `/api/web/*` to `handleWebRequest`. Turns run through the bot's existing turn queue via a new exported `runWebTurn`. Frontend is plain ES-module JS in `public/app/`.

**Tech Stack:** Node 20+, TypeScript (NodeNext ESM), node:http, better-sqlite3, vitest 2, Claude Agent SDK 0.2.141. No new dependencies.

**Spec:** docs/superpowers/specs/2026-10-24-web-ui-design.md (read it; it is binding).

## Global Constraints

- No new npm dependencies, no bundler, no inline `<script>`/`<style>` or `style=`/`on*=` attributes in `public/app/`.
- Every `/api/web/*` route except `POST /api/web/session` requires a valid `havn_web` session AND `isChatAllowed(chatId)`. Box bearer, voice cookies and open-loopback do not grant access.
- Copy for owners is plain language, no em dashes (the character U+2014 must not appear in any new file), no AI cliches.
- No machine-specific paths (tests/no-personal-paths.test.ts). docs/*.md must only reference shipped paths (tests/docs-promise-shipped-paths.test.ts).
- Tests: set env (AGENT_STORE_DIR to a fresh tmp dir, HTTP_BEARER_TOKEN) BEFORE dynamic-importing config/db; HTTP tests start the real server on a random port 5400-5600 and poll `/__ready__` (see tests/http-routes.test.ts).
- Run tests with `/usr/local/bin/node node_modules/vitest/vitest.mjs run <files>`; typecheck with `/usr/local/bin/node node_modules/typescript/bin/tsc --noEmit`. Do NOT use npx (wrong node).
- Known flaky on main before this work: tests/ai-sdk-cancel-delegation.test.ts and tests/wordsmith-template.test.ts (timing). Ignore if they flip; never "fix" them here.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Version 1.48.0. Card numbers in commit titles: #241-#247.

**Interfaces (Produces):**
- `AgentRunOptions.effort?: 'low' | 'medium' | 'high'`.
- `runAgent(message, sessionId?, onTyping?, onPartial?, onToolProgress?, lane='chat', signal?, scope?, opts?: { model?: string; effort?: 'low'|'medium'|'high' })` passes both into `run()`.

- In src/bot.ts:
  ```ts
  export interface WebTurnInput {
    chatId: string            // real allowed chat id (memory, access)
    conversationId: string    // queue key web:<id>
    text: string              // user's text as typed
    framing?: string          // e.g. project framing line, placed before text
    sessionId?: string
    model?: string
    effort?: 'low'|'medium'|'high'
    onQueued?: (ahead: number) => void
    onPartial?: (accumulated: string) => void
    onToolProgress?: (tool: string, status: string) => void
  }
  export interface WebTurnResult { text: string | null; newSessionId?: string; cancelled: boolean; paused?: string }
  export function runWebTurn(input: WebTurnInput): Promise<WebTurnResult>
  export function cancelWebTurn(conversationId: string): CancelResult
  ```

It does NOT touch the `sessions` table. Errors reject (the caller reports them).

### Task 3: Web request dispatcher, hardening, session routes, serving the page

**Files:** Create `src/web/http.ts`, `src/web/respond.ts` (json/sse/header helpers). Modify `src/http-server.ts` (one early hook: `if (await handleWebRequest(req, res, url)) return` before the generic GET static fallback and before the OPTIONS CORS handler for `/api/web/*`; `applyCors` must not run for `/api/web/*`). Create placeholder `public/app/index.html` (Task 8 replaces it). Test `tests/web-http.test.ts`.

**Interfaces (Produces):**
- `handleWebRequest(req, res, url: URL): Promise<boolean>` (true = handled). Internally a small route table: `{ method, pattern: RegExp, auth: boolean, handler(ctx) }` where `ctx = { req, res, url, params: string[], chatId: string, sessionIdHash: string, secure: boolean }`. Later tasks add routes via `registerWebRoutes(routes: WebRoute[])` exported from http.ts.
- Security headers (spec section 5) on every handled response. `Cache-Control: no-store` on API.
- `requireJson(req)`; Origin check (present => `new URL(origin).host === req.headers.host`, else 403); uploads exempt from JSON but require `X-Havn-Web: 1`.
- `readJsonCapped(req, max=256KB)`.
- Rate limiter `allowAttempt(ip, now)`: 10 per 10 min on the exchange route; 429 after.
- Pages: `GET /app` and `/app/` -> `public/app/index.html`; `GET /app/<file>` -> file under `public/app/` only, extensions .js .css .svg .png .webmanifest, traversal-safe; other -> 404. Page routes need no session (the shell is inert).
- Session routes:
  - `POST /api/web/session` {token} -> sets cookie, 200 `{ok:true}`; bad -> 401 `{error:'invalid_link'}`. The label comes from the User-Agent, reduced to a browser + OS phrase of at most 60 chars.
  - `GET /api/web/me` -> `{chatId, isPrimary, assistantName}`. assistantName is read from config if one exists (grep ASSISTANT_NAME), else 'Assistant'.
  - `POST /api/web/signout` -> revoke current session, clear cookie.
  - `GET /api/web/sessions` -> list with `current: boolean`.
  - `POST /api/web/sessions/revoke` {idHash} or {others:true}.

### Task 6: File tree, preview and upload

**Files:** Create `src/web/files.ts`, `src/web/file-routes.ts`. Test `tests/web-files.test.ts`.

**Interfaces:**
- `resolveVisible(relPath, root=PROJECT_ROOT): { abs: string; rel: string; isDir: boolean } | null`.
  - Rejects absolute input, NUL, `..` segments after decoding, any hidden segment (spec section 12 dir list, dot segments, NEVER_SEND names, roles.json), and a realpath outside root.
  - Also rejects if any realpath segment relative to root is hidden. This catches a symlink inside root pointing at `store/`.
- `listDir(relPath): { entries: {name, path, isDir, size, modifiedAt}[] }`. Directories come first, then names. Hidden entries are omitted, and the list is capped at 500.
- Routes:
  - `GET /api/web/files?path=` lists a directory.
  - `GET /api/web/files/raw?path=` serves the file with its MIME type from a small map (md/txt/json/csv/log as `text/plain; charset=utf-8`, html as text/plain too so it never renders, png/jpg/jpeg/gif/webp/svg as image (svg served as `text/plain` to avoid script, or `image/svg+xml` with `Content-Security-Policy: default-src 'none'`; pick the CSP option), pdf `application/pdf`, else `application/octet-stream` with `attachment`). `nosniff` on every response.
  - `POST /api/web/files/upload?name=` takes an `application/octet-stream` body, requires `X-Havn-Web: 1`, caps at 25 MB (413 beyond), writes to UPLOADS_DIR with a sanitised name (basename, `[^\w.\- ]` replaced by `_`, no leading dot, at most 120 chars), and never overwrites. Returns `{path}`, relative to root.

  - A second upload of the same name gets suffix -1.
  - Over 25 MB gives 413 (stream a large body; don't allocate 25 MB in memory twice).
